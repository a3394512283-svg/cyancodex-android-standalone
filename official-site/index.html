生成器怎么用

填几个参数，直接得到能用的命令方块指令

T显 / 计分板

输入计分项名称、显示名与玩家分数，得到计分板创建与显示指令；切换到 T显模式还能生成 titleraw 字幕。

/scoreboard objectives add sb dummy "分数"
/scoreboard objectives setdisplay sidebar sb
/scoreboard players set Steve sb 10

穷举

模板 + 变量候选值，自动做笛卡尔积批量展开，一次生成成百上千条指令。

模板: give @p {item} {n}
变量: item = apple, bread    n = 1, 2

give @p apple 1
give @p apple 2
give @p bread 1
give @p bread 2

滚动字幕

按空格分词做轮播公告，或生成逐字盔甲架横幅，附带节拍器与复位指令。

/scoreboard objectives add cyx_scroll dummy "滚动字幕"
/execute as @a run scoreboard players add @s cyx_scroll 1
/execute as @a if score @s cyx_scroll matches 1 run titleraw @a title {"rawtext":[{"text":"欢迎来到服务器","color":"gold"}]}

音乐生成器

在网格里放音符，自动按 tick 分组生成 playsound 指令，16 种乐器可选。

/execute as @a if score @s cyx_music matches 0 run playsound note.harp @s ~ ~ ~ 1 0.500
/execute as @a if score @s cyx_music matches 1 run playsound note.bell @s ~ ~ ~ 1 1.000

T显 JSON 编辑器

把文字、玩家名、分数、翻译等元素拼成 rawtext，实时预览玩家看到的效果。

/titleraw @a title {"rawtext":[
  {"text":"欢迎 "},
  {"selector":"@p"},
  {"text":" 你的分数 "},
  {"score":{"name":"@s","objective":"sb"}}
]}

码

手写 Java 插件

实现 CyanPlugin 接口（可选 BackgroundProvider），用 javac 编译、d8 转 dex、 放进插件目录即可，App 内置「开发者示例插件」带完整注释。

public class DemoPlugin implements CyanPlugin {
  public String getId()   { return "dev.cyancodex.demo"; }
  public String getName() { return "我的插件"; }
  public void onEnable(Context ctx) { }
  public void onDisable() { }
}

常见问题

CyanCodex 是免费的吗？

App 免费下载使用，指令库、生成器、插件工坊等功能都不收费；AI 助手按积分计费，签到、分享、活动都能获取积分。

有没有不用联网的版本？

有，就是上面的 离线版（下载）：只保留生成器，不联网、不登录、不需要账号，安装包没有申请联网权限，占用更小。它和完整版包名不同，可以同时安装；需要指令库、AI、广告拦截等功能时，用完整版即可。

Cyan工具箱是什么？和主 App 什么关系？

Cyan工具箱是另一个独立 App（下载），只放通用小工具：JSON / Base64 / 哈希、进制 / 时间戳 / 颜色 / 单位换算、随机密码 / 二维码、设备信息 / DNS / 端口检测。它和主 App 没有功能重叠，唯一的联系是账号互通——用同一个沧蓝工坊账号登录（可看积分、签到），不登录也能用全部工具。三个 App（完整版 / 离线版 / 工具箱）包名都不同，可以同时安装。

Java 版怎么安装？

下载上面的 Java 版 .jar（1.20.1–1.21.8 用通用包，26.2 用对应包），然后：

  1. 先装 Fabric Loader（选你的游戏版本），启动一次游戏生成 mods 文件夹；
  2. 把下载的 .jar 放进 mods 文件夹，重开游戏；
  3. 进游戏后打开 CyanCodex 面板，用 App 账号登录或填开放 API 密钥即可查指令、问 AI；
  4. 模组不修改游戏本体、不联机注入，卸载只需删掉那个 jar（26.2 需要 Java 25）。
插件工坊生成的插件安全吗？

插件运行在 App 内，只能使用我们开放的接口（自定义背景、日志、配置等），不会读取你的账号数据；手写插件也只在本地运行。

开放 API 怎么申请？

注册 CyanCodex 账号后进入开发者平台，用「账号密码 + 图形验证码 + 邮箱验证码 + App 站内信验证码」登录即可创建密钥，默认每日 2000 次调用。

数据存在哪里？会不会丢？

账号、指令、聊天室等数据都在服务器数据库中，聊天室消息还会在本地管理端归档成 JSON 长期保留，可用于追溯。
