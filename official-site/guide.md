# A. 手机 App 使用方法

## ① 安装与登录

1. 到官网下载区点「Android → 下载 APK」；也可以直接用网页版 https://app.blueworkshop.top/web/ （免安装）。
2. 安装时若提示「不允许安装未知应用」，允许一次即可（只在首次安装时需要）。
3. 打开 App → 注册账号（用户名 + 邮箱 + 密码，邮箱用于找回密码）或直接登录。
4. 登录后如果提示「版本过低」，点弹窗里的「下载安装」一键升级即可。

> 建议顺手在「我的 → 设置」里开一次通知权限，审核结果、审核员私信、公告都能收到推送。
> 「输入法模式」和「悬浮窗」是可选功能，需要在系统设置里给一次权限。

## ①-b 离线版（只有生成器，不联网）

只想用生成器、不想要账号和联网功能的话，可以装 **CyanCodex 离线版**：
下载 <https://app.blueworkshop.top/downloads/CyanCodex-Offline-v1.0.1.apk>（v1.0.1 · 2.02 MB）

- **包含**：T显生成器、穷举、滚动字幕、音乐生成器（含 MIDI 导入试听）、T显 JSON 编辑器、生成历史。
- **不包含**：指令库、AI 助手、广场、账号与签到、插件、输入法、悬浮窗、广告拦截、网络测速。
- **真离线**：安装包没有申请联网权限（手机「设置 → 应用 → 该应用 → 流量」可验证），不登录、无后台服务，生成记录只存在本机。
- **可共存**：包名与完整版不同，两个 App 能同时安装；图标底色青蓝 = 离线版，深绿 = 完整版。
- 用法与完整版一致：填参数 → 生成指令 → 一键复制 → 粘贴到游戏聊天栏或命令方块。
- 离线版不会自动更新，升级请回官网下载新安装包覆盖安装（本机历史不受影响）。

## ①-c Cyan工具箱（实用小工具，账号互通）

**Cyan工具箱**是另一个独立 App，只放通用小工具：
下载 <https://app.blueworkshop.top/downloads/CyanToolbox-v1.0.5.apk>（v1.0.5 · 2.15 MB）

- **文本工具**：JSON 格式化 / 压缩 / 校验、Base64（文本与图片互转）、MD5 / SHA-1 / SHA-256 / CRC32 与字数统计、URL 编解码、乱码修复。
- **转换工具**：2-36 任意进制互转、时间戳 ↔ 日期（带时区）、颜色 HEX / RGB / HSL 互转、长度 / 重量 / 面积 / 体积 / 数据 / 时间 / 温度单位换算。
- **生成工具**：安全随机密码（可设长度与字符集、显示强度）、二维码生成（可保存到相册）。
- **系统工具**：设备信息（机型 / 系统 / 屏幕 / CPU / 内存 / 存储 / 电池）、本机 IP、DNS 解析、TCP 端口连通性测试。
- **账号互通**：用同一个沧蓝工坊账号登录（与主 App、官网同账号），可看资料与积分、每日签到；**不登录也能用全部工具**。
- **与主 App 的关系**：功能上完全不重叠，唯一联系是账号；工具全部本机运算，输入内容不上传。三个 App 包名不同，可同时安装。

## ② 首页与模块

首页就是总入口：顶部显示积分与签到，中间是公告横幅，下面是各个功能模块。

- **长按模块**可以隐藏／恢复（不喜欢的功能可以收起来）。
- 底部 6 个页签：首页 / 指令库 / 广场 / 生成器 / AI / 我的。
- 每个页面底部都有一条「宝贝回家」公益信息，点一下能看详情。

![首页](https://cyancodex.cn/assets/guide/01-home.webp)

## ③ 指令库：浏览、搜索、复制

- 顶部页签：**平台 / 高质 / 低质 / 我的 / 收藏 / 教程** 分类浏览。
- 搜索框输入关键字（如 `tnt`）即可检索；命中的关键词会高亮。
- 卡片上直接点复制图标 → 复制指令全文；也可以点进详情复制单行、看效果图与附件。
- 自己上传的指令在「**我的**」里，能看审核状态（待审核 / 已通过 / 已驳回 + 原因），可编辑、可删除。

![指令库](https://cyancodex.cn/assets/guide/02-library.webp)
![搜索指令](https://cyancodex.cn/assets/guide/03-library-search.webp)

## ④ 指令编辑器（含附件上传）

1. 首页 →「指令编辑器」，或者指令库右上角的 + 号。
2. 每行 = 一个命令块：可「整段粘贴」（自动按换行分块）、逐行编辑、快捷插入 `@p` / `~` / `^` 等参数，还有命令补全提示。
3. 「打开指令文件」可以直接导入 TXT（每行一个命令块）。
4. 选中一行后还能设置命令方块属性：方块类型（脉冲 / 连锁 / 循环 / 聊天栏）、连锁模式、红石控制、延迟刻。
5. **附件**：可以添加 txt / json / mcfunction / 图片 / zip / mcpack 等文件（最多 5 个，单个 ≤6MB、合计 ≤8MB）；**也可以只发附件、指令内容留空**——有些作者就是用文件发指令的。
6. 填标题后点「上传到指令库」提交审核；已上传的点「更新到指令库」可编辑，也能在这里增删附件。

> 附件里的文字内容同样会被审核（比如文件里写 `/op 某某` 会被直接驳回），不用担心有人用文件绕过审核。

![编辑器附件区](https://cyancodex.cn/assets/guide/12-editor-attach.webp)

## ⑤ 生成器（不用记语法）

- **T显生成器**：计分板 / 标题，输入文字直接出 `titleraw` 指令。
- **穷举**：批量生成不同数值的指令。
- **滚动字幕**：公告、字幕滚动效果。
- **音乐生成器**：命令方块音乐（`note.*` 音效）。
- 生成结果可以一键复制，也能存进「生成历史」下次接着用。

![生成器](https://cyancodex.cn/assets/guide/04-generators.webp)

## ⑥ AI 助手

- 直接描述需求即可，例如「给我一个钻石剑带锋利 5 的指令」「做个倒计时计分板」。
- **按量计费**：基础 5 积分 + 按 Tokens 计费，顶部能看到余额与本次消耗。
- AI 内置了整套基岩版物品表（7977 条），所以它给的 ID 是准的，不会瞎编；你也可以用「快捷查询 ID」自己核对。
- 常见问题会命中「社区经验库」直接秒答，不消耗积分；每条回答都能点「有用 / 没用」帮它变准。

> 积分不够时：每日签到、看公益广告都能拿积分（见第 ⑧ 节）。

![AI 助手](https://cyancodex.cn/assets/guide/05-ai.webp)

## ⑦ 快捷查询 ID

1. 入口：**首页「快捷查询ID」**、我的、每日签到页，以及指令编辑器右上角的搜索图标。
2. 输入**中文**（钻石剑、锋利、铜粒…）或英文 ID（`copper_nugget`）→ 直接出结果。
3. 点结果里的 ID 即可复制；上方可以按分类筛选（物品 / 方块 / 实体 / 附魔 / 药水效果 / 配方…）。

一共 **7977 条**基岩版参考数据，找不到的可以换个说法，或者直接用 AI 问。

![快捷查询 ID](https://cyancodex.cn/assets/guide/07-mcid.webp)

## ⑧ 积分：签到 / 看广告 / 转账

- **每日签到**：基础 +20，连续签到每天额外 +5（封顶 +50），断签重新累计。
- **看广告得积分**：完整看完一条央视公益广告 **+50 积分**，每天最多 20 次。必须看完才能领，看一半不给。
- **积分转账**：转给好友，手续费 20%。
- **积分明细**：每一笔增加 / 消耗都有记录。

页面：我的 → 每日签到 / 看广告得积分 / 积分明细 / 积分转账。

![看广告得积分](https://cyancodex.cn/assets/guide/08-ad-reward.webp)

## ⑨ 聊天室、好友与广场

- **聊天室**：首页「聊天室」进入，实时交流指令；长按别人的消息可以举报。
- **好友**：加好友、私聊；消息里有违规内容同样可举报。
- **广场**：看最新的指令与评论动态；指令详情里能评论、点赞、收藏。
- 聊天室里点别人头像可以进他的主页，看他上传的指令。

![聊天室](https://cyancodex.cn/assets/guide/11-chat.webp)

## ⑩ 五子棋（内置小游戏）

- 四种玩法：**人机对战**（简单 / 普通 / 困难 / 老叟戏顽童 / 顽童宗师）、**匹配对手**、**房间大厅**（按房间号加入、踢人、观战）、**AI 观战**（两个 AI 自动对弈，可调速、可分别设置黑白强度）。
- 高难度 AI 会「边下边嘲讽」，还会发动【神之一手】抢走你的必赢棋。

![五子棋](https://cyancodex.cn/assets/guide/10-gomoku.webp)

## ⑪ 宝贝回家（公益）

- 每个页面底部都有一条公益信息条，轮播走失儿童的寻亲信息，点「查看」进入列表。
- 点开某一条可以看：姓名 / 性别 / 走失时间地点 / 体貌特征 / 官方联系方式，另外可以**一键分享**或**拨打 110**。
- 数据来自「宝贝回家」寻子网，仅用于公益传播；**权威信息以警方发布为准**。

> 如果你看到疑似走失、被拐儿童，请第一时间拨 110，不要自行处置，也不要在网上发布未经核实的信息。

![宝贝回家](https://cyancodex.cn/assets/guide/09-babyhome.webp)

## ⑫ 个人中心与账号安全

- 「我的」页面可以改头像、昵称、性别，查看积分与 AI 解锁状态。
- **修改密码**后，其它设备上的旧登录会立即失效；**退出登录**会同时注销服务器上的令牌。
- 可以绑定 / 更换邮箱，开启**两步验证**（开启前需要先输入当前密码）。
- 还有：站内信、意见申诉（有问题、有建议都能提）。

![个人中心](https://cyancodex.cn/assets/guide/06-profile.webp)

# B. Java 版（Fabric 模组）使用方法

## ① 先选对包

| 你的游戏版本 | 下载哪个 | 额外要求 |
| --- | --- | --- |
| 1.20.1 – 1.21.8 | **1.20.1–1.21.8 通用包**（一个包覆盖中间所有版本） | Fabric Loader + Fabric API（对应版本） |
| 26.2（最新版） | **26.2 包** | 需要 **Java 25**；Fabric API 26.2 版 |

下载地址：官网下载区 →「Java 版 · 模组」/「Java 版 · 26.2」。

> 为什么是两个包：Minecraft 从 26.1 起官方取消了代码混淆，Fabric 也随之换了映射体系，所以 26.x 与 1.21.x 及以前不可能合成同一个 jar——这是平台限制。

## ② 安装（3 步）

1. 用官方安装器给对应版本装一次 **Fabric Loader**：https://fabricmc.net/use/installer/ ，装完启动一次游戏，会生成 `.minecraft/mods` 文件夹。
2. 下载 **Fabric API**（对应版本）丢进 `mods`，再下载本模组的 jar 丢进同一个文件夹。
   - 参考版本：1.20.1 用 `0.92.12+1.20.1`；1.21.8 用 `0.136.1+1.21.8`；26.2 用 `0.160.0+26.2`。
3. 用 Fabric 启动器打开游戏。纯客户端模组，**服务器不用装**。

## ③ 游戏内怎么用

进游戏后按 **K** 打开 / 关闭 CyanCodex 界面。

| 操作 | 说明 |
| --- | --- |
| **K** | 打开 / 关闭界面 |
| 点列表行 | 1.20.1~1.21.8 版：选中该行；26.2 版：直接复制 |
| 复制 | 复制到剪贴板，切回游戏 `Ctrl + V` 粘进聊天框 |
| 执行 | 以你的身份直接执行该指令（**需要 OP 权限**） |
| 收藏 / 刷新 / ◀ ▶ | 收藏当前行 / 重新拉取 / 翻屏 |

页签：

- **指令库**：搜指令、翻页。
- **生成器**：T显计分板 / 穷举 / 滚动字幕 / 音乐 / T显 JSON，输出 **Java 版语法**（`/title @a title {"text":...}`、`/playsound minecraft:block.note_block.harp …`），和手机端基岩版语法不同，别混用。
- **AI 助手**：和手机上同一个 AI，直接问它要指令。
- **收藏**：存自己喜欢的指令。
- **设置**：填接口地址与 API 密钥。

## ④ 配置 API 密钥（用生成器和 AI 才需要）

1. 手机上打开 App →「我的 → 开发者/API」（或网页版开发者平台）创建一把 API 密钥，默认每天 2000 次。
2. 回到游戏按 **K** → **设置** 页签 → 填 **接口地址**（默认 `https://app.blueworkshop.top`）和 **API 密钥** → 点「保存并测试」。
3. 底部显示 `今日剩余 xxxx / 2000` 就说明通了。

配置写到 `.minecraft/config/cyancodex.json`（密钥只存在你本机）。

> **指令库是公开接口，不填密钥也能用**；只有生成器和 AI 需要密钥。AI 与生成器共用同一把密钥的每日额度。

## ⑤ 卸载 / 出问题怎么办

- **卸载**：删掉 `mods` 里的 jar 即可，游戏本体不受影响（模组不修改游戏文件、不联机注入）。
- **界面打不开**：确认 Fabric Loader + Fabric API 都装了、版本对得上；再看 `.minecraft/logs/latest.log` 有没有报错。
- **版本不匹配**：1.21.9 ~ 26.1 之间暂时没有包（映射体系刚换）；26.2 用 26.2 包，其余用通用包。
- **生成器 / AI 报 401**：密钥没填对或额度用完，重新创建一把即可。

# C. 常见问题

**App 装不上 / 提示「不允许安装未知应用」**
这是安卓的安全限制：允许一次「安装未知应用」权限就行。APK 请从官网或 App 内更新获取。

**积分怎么来？**
每日签到（+20 起，连签更多）、看公益广告（每次 +50，每天最多 20 次）、活动奖励、好友转账（手续费 20%）。积分用于 AI 按量计费等场景。

**上传的指令多久能通过？**
工作日有 AI 自动审核，通常几分钟内出结果；被驳回会写明原因，改完重新提交即可。周末的 AI 自动审核需要开发者邮件授权后才开启。

**为什么有的指令要积分才能看？**
那是作者设置的「付费指令」：支付对应积分后即可查看，积分直接给作者，平台不收。

**Java 版和手机端的指令能通用吗？**
语法不同：手机端是基岩版（`titleraw` / `note.harp` / 计分板 dummy），Java 版模组输出 Java 语法（`title` / `minecraft:block.note_block.*`）。两边都会按各自版本生成，注意别混用。

**换手机后数据还在吗？**
在。账号、积分、上传的指令、聊天记录都在服务器上，登录同一账号即可；只有「快捷指令」等本机设置需要重新加。
