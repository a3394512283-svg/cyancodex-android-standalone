A手机 App 使用方法

① 安装与登录

  1. 到 下载区 点「Android → 下载 APK」；也可以直接用网页版（免安装）。
  2. 安装时若提示「不允许安装未知应用」，允许一次即可（只在首次安装时需要）。
  3. 打开 App → 注册账号（用户名 + 邮箱 + 密码，邮箱用于找回密码）或直接登录。
  4. 登录后如果提示「版本过低」，点弹窗里的「下载安装」一键升级即可。
建议顺手在「我的 → 设置」里开一次通知权限，审核结果、审核员私信、公告都能收到推送。
另外「输入法模式」和「悬浮窗」是可选功能，需要在系统设置里给一次权限。

①-b 离线版（只有生成器，不联网）

如果只想用生成器、不想要账号和联网功能，可以装 CyanCodex 离线版： 下载离线版 APK（v1.0.1 · 2.02 MB）。

  • 包含：T显生成器、穷举、滚动字幕、音乐生成器（含 MIDI 导入试听）、T显 JSON 编辑器、生成历史。
  • 不包含：指令库、AI 助手、广场、账号与签到、插件、输入法、悬浮窗、广告拦截、网络测速。
  • 真离线：安装包没有申请联网权限（手机「设置 → 应用 → 该应用 → 流量」可验证），不登录、无后台服务，生成记录只存在本机。
  • 可共存：包名与完整版不同，两个 App 能同时安装；图标底色青蓝 = 离线版，深绿 = 完整版。
  • 用法与完整版一致：填参数 → 生成指令 → 一键复制 → 粘贴到游戏聊天栏或命令方块。
  • 生成历史在首页「生成历史」里，长按可删除单条；历史只在本机，卸载 App 会一起清掉。
离线版不会自动更新，想升级请回官网下载新的安装包覆盖安装（数据不受影响）。

①-c Cyan工具箱（实用小工具，账号互通）

Cyan工具箱是另一个独立 App，只放通用小工具： 下载工具箱 APK（v1.0.5 · 2.15 MB）。

  • 文本工具：JSON 格式化 / 压缩 / 校验、Base64（文本与图片互转）、MD5 / SHA-1 / SHA-256 / CRC32 与字数统计、URL 编解码、乱码修复（UTF-8 被当 GBK / Latin-1 等）。
  • 转换工具：2-36 任意进制互转、时间戳 ↔ 日期（带时区）、颜色 HEX / RGB / HSL 互转、长度 / 重量 / 面积 / 体积 / 数据 / 时间 / 温度单位换算。
  • 生成工具：安全随机密码（可设长度与字符集、显示强度）、二维码生成（可保存到相册）。
  • 系统工具：设备信息（机型 / 系统 / 屏幕 / CPU / 内存 / 存储 / 电池）、本机 IP、DNS 解析、TCP 端口连通性测试。
  • 开发工具：环境安装教程（Java/Python/Node/Go/C++/Termux/ADB/Git）、网页源码提取、APK 解析（包名/版本/SDK/权限/四大组件）、世界 15 城市时区。
  • 文件与系统：已装应用提取 APK、文件哈希校验、屏幕测试（坏点/漏光）、电池健康、文本朗读、验证码提取（粘贴即取，不要短信权限）。
  • 网络工具：端口扫描、局域网设备发现、网速测速（官方服务器做节点）。
  • 悬浮窗音乐：开启通知使用权后，悬浮控制条自动同步 QQ 音乐 / 网易云正在播放的歌，可拖动、可切歌。
  • 账号互通：用同一个沧蓝工坊账号登录（与主 App、官网同账号），可以看资料与积分、每日签到；不登录也能用全部工具。
  • 与主 App 的关系：功能上完全不重叠（主 App 管指令库 / 生成器 / AI），唯一联系是账号；工具全部本机运算，输入内容不上传。
  • 可共存：包名不同，工具箱 / 完整版 / 离线版三个 App 能同时安装（图标底色紫罗兰 = 工具箱）。
工具箱注册仍走主 App 或官网（要图形验证码 + 邮箱码），登录后即可看积分与签到。

③ 指令库：浏览、搜索、复制

  • 顶部页签：平台 / 高质 / 低质 / 我的 / 收藏 / 教程 分类浏览。

④ 指令编辑器（含附件上传）

  1. 首页 →「指令编辑器」，或者指令库右上角的 + 号。
  2. 每行 = 一个命令块：可「整段粘贴」（自动按换行分块）、逐行编辑、快捷插入 @p/~/^ 等参数，还有命令补全提示。
  3. 「打开指令文件」可以直接导入 TXT（每行一个命令块）。
  4. 选中一行后还能设置命令方块属性：方块类型（脉冲/连锁/循环/聊天栏）、连锁模式、红石控制、延迟刻。
  5. 附件：可以添加 txt / json / mcfunction / 图片 / zip / mcpack 等文件（最多 5 个，单个 ≤6MB、合计 ≤8MB）；也可以只发附件、指令内容留空——有些作者就是用文件发指令的。
  6. 填标题后点「上传到指令库」提交审核；已上传的点「更新到指令库」可编辑，也能在这里增删附件。
附件里的文字内容同样会被审核（比如文件里写 /op 某某 会被直接驳回），所以不用担心有人用文件绕过审核。

  • 穷举：批量生成不同数值的指令。

⑥ AI 助手

  • 直接描述需求即可，例如「给我一个钻石剑带锋利 5 的指令」「做个倒计时计分板」。
  • 按量计费：基础 5 积分 + 按 Tokens 计费，顶部能看到余额与本次消耗。
  • AI 内置了整套基岩版物品表（7977 条），所以它给的 ID 是准的，不会瞎编；你也可以用「快捷查询 ID」自己核对。
  • 常见问题会命中「社区经验库」直接秒答，不消耗积分；每条回答都能点「有用 / 没用」帮它变准。
积分不够时：每日签到、看公益广告都能拿积分（见第 ⑧ 节）。

BJava 版（Fabric 模组）使用方法

① 先选对包

你的游戏版本下载哪个额外要求
1.20.1 – 1.21.81.20.1–1.21.8 通用包（一个包覆盖中间所有版本）Fabric Loader + Fabric API（对应版本）
26.2（最新版）26.2 包需要 Java 25；Fabric API 26.2 版

下载地址就在官网下载区（Java 版 · 模组 / Java 版 · 26.2）。

为什么是两个包：Minecraft 从 26.1 起官方取消了代码混淆，Fabric 也随之换了映射体系，所以 26.x 与 1.21.x 及以前不可能合成同一个 jar——这是平台限制，不是我们偷懒。

② 安装（3 步）

  1. 用官方安装器给对应版本装一次 Fabric Loader：fabricmc.net/use/installer，装完启动一次游戏，会生成 .minecraft/mods 文件夹。
  2. 下载 Fabric API（对应版本）丢进 mods，再下载本模组的 jar 丢进同一个文件夹。
    参考版本：1.20.1 用 0.92.12+1.20.1；1.21.8 用 0.136.1+1.21.8；26.2 用 0.160.0+26.2。
  3. 用 Fabric 启动器打开游戏。纯客户端模组，服务器不用装。

③ 游戏内怎么用

进游戏后按 K 打开 / 关闭 CyanCodex 界面。顶部页签：

  • 指令库：搜指令、翻页，点行选中，再点「复制」或「执行」。
  • 生成器：T显计分板 / 穷举 / 滚动字幕 / 音乐 / T显 JSON，输出的是 Java 版语法（/title @a title {"text":...}、/playsound minecraft:block.note_block.harp …），和手机端基岩版语法不同，这点别搞混。
  • AI 助手：和手机上同一个 AI，直接问它要指令。
  • 收藏：存自己喜欢的指令；设置：填接口地址与 API 密钥。

④ 配置 API 密钥（用生成器和 AI 才需要）

  1. 手机上打开 App →「我的 → 开发者/API」（或在网页版开发者平台）创建一把 API 密钥，默认每天 2000 次。
  2. 回到游戏按 K → 设置 页签 → 填 接口地址（默认 https://app.blueworkshop.top）和 API 密钥 → 点「保存并测试」。
  3. 底部显示 今日剩余 xxxx / 2000 就说明通了。

配置会写到 .minecraft/config/cyancodex.json（密钥只存在你本机）。

指令库是公开接口，不填密钥也能用；只有生成器和 AI 需要密钥。AI 与生成器共用同一把密钥的每日额度。

⑤ 卸载 / 出问题怎么办

  • 卸载：删掉 mods 里的 jar 即可，游戏本体不受影响（模组不修改游戏文件、不联机注入）。
  • 界面打不开：先确认 Fabric Loader + Fabric API 都装了、版本对得上；再看 .minecraft/logs/latest.log 有没有报错。
  • 提示版本不匹配：1.21.9 ~ 26.1 之间暂时没有包（映射体系刚换），26.2 用 26.2 包，其余用通用包。
  • 生成器/AI 报 401：密钥没填对或额度用完，重新创建一把即可。

C常见问题

App 装不上 / 提示「不允许安装未知应用」

这是安卓的安全限制：允许一次「安装未知应用」权限就行。下载的 APK 请从官网或 App 内更新获取，别用第三方渠道的包。

离线版和完整版有什么区别？装哪个？

离线版只有生成器，不联网、不登录、不用账号，安装包更小（下载）；完整版多了指令库、AI 助手、广场、账号签到、插件、广告拦截、网络测速等功能。只想生成指令就装离线版，想要指令库和 AI 就装完整版；两个包名不同，也可以都装上。

Cyan工具箱里有啥？要单独注册账号吗？

工具箱是通用小工具合集（下载）：JSON / Base64 / 哈希、进制 / 时间戳 / 颜色 / 单位换算、随机密码 / 二维码、设备信息 / DNS / 端口检测。不用单独注册——用你的沧蓝工坊账号登录即可（和主 App、官网同一个账号），登录后能看积分、签到；不登录也能用全部工具。

积分怎么来？

每日签到（+20 起，连签更多）、看公益广告（每次 +50，每天最多 20 次）、活动奖励、好友转账（手续费 20%）。积分用于 AI 按量计费等场景。

上传的指令多久能通过？

工作日有 AI 自动审核，通常几分钟内就有结果；被驳回会写明原因，改完重新提交即可。周末的 AI 自动审核需要开发者邮件授权后才开启。

为什么有的指令要积分才能看？

那是作者设置的「付费指令」：支付对应积分后即可查看。积分直接给作者，平台不收。

Java 版和手机端的指令能通用吗？

语法不同：手机端是基岩版（titleraw / note.harp / 计分板 dummy），Java 版模组输出的是 Java 语法（title / minecraft:block.note_block.*）。两边都会按各自版本生成，复制时注意别混用。

换手机后数据还在吗？

在。账号、积分、上传的指令、聊天记录都在服务器上，登录同一个账号即可；只有「快捷指令」等本机设置需要重新加。
