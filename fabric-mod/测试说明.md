# CyanCodex Fabric 模组 · 测试说明

## 一、装什么

| 你的游戏版本 | 装哪个包 | 配哪个 Fabric API |
|---|---|---|
| 1.20.1 | `cyancodex-fabric-1.0.0+1.20.1-1.21.8.jar` | `fabric-api-0.92.12+1.20.1` |
| 1.21.1 | 同上（通用包） | `fabric-api-0.116.17+1.21.1` |
| 1.21.8 | 同上（通用包） | `fabric-api-0.136.1+1.21.8` |
| 26.2 | `cyancodex-fabric-1.0.0+26.2.jar` | `fabric-api-0.160.0+26.2` |

步骤：Fabric 安装器装对应版本 Loader → 把 Fabric API 与本模组的 jar 一起丢进 `.minecraft/mods/` → 启动。
模组是纯客户端（`environment: client`），**服务端不用装**。

## 二、先配密钥

进游戏按 **K** → **设置** → 接口地址 `https://app.blueworkshop.top`、密钥 `cyx_b229dfcad2333d96d5ba6562e44d3ceaebbdaa49`（演示密钥，2000 次/天）→ 保存并测试，底部出现 `今日剩余 xxxx / 2000` 即可。
不填密钥也能用**指令库**（公开接口），只有生成器和 AI 需要密钥。

## 四、待测：通用包在 1.21.1 / 1.21.8 上

> 我只做了静态验证（引用的 MC API 在目标版本 21/21 全部存在），**没有实机跑过**。请重点看：

1. **能否打开**：按 K 出界面、5 个页签能点、不崩游戏。
2. **布局**：1.21.x 的控件外观与 1.20.1 略有差异，看按钮有没有重叠/出屏（默认窗口 + 全屏各一次）。
3. **指令库**：能出列表、搜索 `T显` 能过滤、点行→复制→游戏里粘贴内容一致。
4. **生成器**：5 个各点一次「⚡ 生成 Java 版指令」，确认返回的是 Java 语法（`/title ... {"text":...}`、`/playsound minecraft:block.note_block.*`、`give @p minecraft:apple`），没有 `titleraw` / `note.harp`。
5. **AI 助手**：输入「给我一条让所有玩家获得夜视效果的指令」看是否返回可用指令。
6. **执行**（你是 OP 时）：选一条 `/title` 点执行，游戏里真的出标题。
7. **收藏**：收藏一条 → 切收藏页可见 → 退出游戏重进还在。

如果 1.21.x 上崩了，把 `.minecraft/logs/latest.log` 里含 `CyanCodex` 的行发我（大概率是某个 API 签名在目标版本变了，改一处即可）。

## 五、待测：26.2 包（改动最大，重点看）

26.2 的渲染模型整个换了（`GuiGraphics` → `GuiGraphicsExtractor`），所以 **26.2 版的界面是重写的、只用原版控件、不做任何自定义绘制**，也没法在我这边实机验证。请重点看：

1. **能否打开**：按 K 出界面（键位注册在 26.2 改了 API，这是最可能出问题的一环）。
2. **界面是否完整**：顶部标题、5 个页签、控件、列表行按钮、底部操作栏、状态提示是否都在、能点。
3. **交互差异**：26.2 版是「**单击列表行 = 直接复制**」，底部「执行选中」作用于最近点过的那一行（1.20.1 版是点行选中后用复制按钮）。
4. **生成器 / AI / 指令库 / 设置**：同上第 3~7 项。
5. **退出**：按 ESC 能正常关闭界面，不卡死。

26.2 上如果有问题，多半是这三处之一（我已按 26.2 的新 API 写好，但没实机验证）：
- `KeyMapping.Category.register(Identifier)` 注册分类
- `Minecraft#setScreenAndShow` 打开界面
- `EditBox` / `Button` / `StringWidget` 的构造与坐标
