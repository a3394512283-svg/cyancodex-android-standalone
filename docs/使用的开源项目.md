# 使用的开源项目

本项目在官方开源工程的基础上做了「共存版改造 + 液态玻璃 + UI 改造」。
下面按**改造引入**和**上游原有**两类列出全部第三方依赖，含版本与许可。

> 所有依赖均为**宽松许可（Apache-2.0）**，无 GPL/LGPL 传染性依赖，
> 与项目自身的 GPLv3 许可兼容。

---

## 一、改造引入的开源项目（重点）

### 1. Kyant0 / AndroidLiquidGlass —— 液态玻璃核心

这是本次改造**最关键**的第三方库，提供 iOS 26 风格的 Liquid Glass 渲染能力。

| 项 | 值 |
| --- | --- |
| 仓库 | https://github.com/Kyant0/AndroidLiquidGlass |
| 作者 | Kyant (Kyant0) |
| 许可 | **Apache License 2.0** |
| Maven 坐标 | `io.github.kyant0:backdrop:2.0.0` |
| 配套形状库 | `io.github.kyant0:shapes:1.2.0`（同作者、同许可） |

**它提供什么**

- `rememberLayerBackdrop()` / `Modifier.layerBackdrop()` —— 把某个节点的**后续绘制内容**录制为采样源
- `Modifier.backdrop(...)` —— 对采样源做 `blur` + `lens` 折射，得到玻璃质感
- `DampedDragAnimation` / `InteractiveHighlight` —— 拖拽阻尼与按压高光
- 高层组件：`LiquidButton` / `LiquidToggle` / `LiquidBottomTabs`

**本项目怎么用**

- `ui/liquidglass/` 目录是**官方组件的搬运与少量适配**（9 个文件）
- 官方组件的源码改动只有两处：
  1. `LiquidToggle.kt` 把写死的 iOS 绿提成 `accentColor` 参数
  2. `LiquidButton.kt` / `LiquidToggle.kt` 新增 `flatSource: Boolean = false` 开关
     —— 采样源是**平底色**时跳过 blur + lens（数学上是恒等变换，但着色器照样跑）
- 自封装层在 `ui/components/GlassControls.kt`，把官方组件包装成 `GlassSwitch` /
  `GlassActionButton` / `GlassFilterChip` / `GlassIconButton` 等，统一 Material 令牌映射

**⛔ 版本必须锁 `2.0.0` / `1.2.0`，不要升到 `2.0.1` / `1.2.1`**

`2.0.1` 与 `2.0.0` 的**公开 API 完全相同**（已用 `javap` 逐个核对：`PlatformKt` 的
`isRuntimeShaderSupported`、`RuntimeShaderKt` 的 `RuntimeShader` + `asComposeShader`、
`shapes` 的 `Capsule` 构造签名 —— 一字不差）。`2.0.1` 唯一的变化是**改用 Kotlin 2.4.0 重新编译**，
于是 `META-INF/*.kotlin_module` 的元数据版本从 `2.3.0` 变成 `2.4.0`。
本工程用的是 Kotlin 2.2.10，最多只能读 `2.3.0` 的元数据 → 升上去会得到满屏
`Module was compiled with an incompatible version of Kotlin`，以及一堆由
kotlin-stdlib 2.4.10 被拖进来引发的假报错（`Unresolved reference 'runCatching'` 等）。

> 查元数据版本字节：`kotlin_module` 头部第 4 个 `u32`，`3` = 2.3.0 / `4` = 2.4.0。

**能力门槛（API 级别）**

| 效果 | 最低 API |
| --- | --- |
| `blur` 模糊 | Android 12（API 31） |
| `lens` 折射（AGSL 着色器） | Android 13（API 33） |

低版本没有折射**不是参数问题**，是硬件/系统能力不支持。本项目 `minSdk 26`，
在 API 31/33 以下会自动退化为普通半透明色块。

## 一之二、2026-10-01「AI Agent 改造」引入的依赖：**零**

AI 页那一整块改造（自备 Key 直连 / 多对话 / 智能搜索 / 思考实测，见 `docs/实现逻辑.md` §14）
**没有新增任何第三方依赖** —— 全部用工程已有的 `OkHttp` + Android 内置的 `org.json` 手写请求，
没引 SDK、没引搜索库、没引 Gson 之外的东西。

需要说清楚的是：改造里接的那些 **AI 供应商**和**搜索引擎**是**外部服务**，不是开源库 ——
它们不随本包分发，使用者也**不需要**它们的 SDK：

| 类别 | 清单 | 说明 |
| --- | --- | --- |
| AI 对话供应商（7 家预设 + 自定义） | DeepSeek / OpenAI / 通义千问 / Kimi / 智谱 GLM / 硅基流动 / OpenRouter | 全部走 OpenAI 兼容的 `/chat/completions` HTTP 接口，用**使用者自己的 API Key** |
| 搜索引擎（7 家） | Exa / TinyFish / Brave / Serper / 智谱联网 / Tavily / 博查 | 纯 HTTP，用**使用者自己的 API Key**；不配就不显示搜索开关 |

> ⚠️ 这些服务各有自己的服务条款与计费，与开源许可无关。本包**不含**任何 Key、也不代付。

## 四、快速核对

想自己核对依赖树：

```bash
cd android
./gradlew :app:dependencies --configuration releaseRuntimeClasspath
```

想核对 `backdrop` 的许可声明（Gradle 缓存里的 POM）：

```bash
# 路径形如 ~/.gradle/caches/modules-2/files-2.1/io.github.kyant0/backdrop/2.0.0/<hash>/backdrop-2.0.0.pom
grep -A4 '<licenses>' <上面的 pom>
# 应输出: <name>The Apache License, Version 2.0</name>
```
